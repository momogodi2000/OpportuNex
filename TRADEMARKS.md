# Marques / Trademarks

Le code d'Opportunex est sous GNU AGPL v3, mais **les noms « Opportunex » et « PIO » ainsi que le
logo Opportunex ne sont pas couverts par cette licence**. Ils sont réservés à ETS Monthe Network
(décision D-06 ; recherche d'antériorité en cours, voir `documentation/LEGAL_DECISIONS_NEEDED.md`).

## Autorisé sans demande
- Dire que votre logiciel « est basé sur Opportunex » ou « est compatible avec Opportunex ».
- Utiliser le nom pour parler du projet, le citer, le comparer, l'enseigner.
- Redistribuer les versions **officielles non modifiées** avec leur nom et leur logo.

## Soumis à autorisation
- Distribuer une version **modifiée** (fork) sous le nom ou avec le logo Opportunex : renommez-la et
  remplacez le logo (`packaging/branding/`, `apps/desktop/assets/images/`).
- Exploiter un service public de synchronisation présenté comme « officiel » Opportunex.
- Utiliser le logo sur des produits ou services commerciaux.

*In short: the AGPL covers the code, not the brand. Forks must use another name and logo. Factual use of the
name ("based on Opportunex") is fine.*
